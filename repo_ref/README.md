# repo_ref/

Motores de análisis y simulación en Python (ranking Chance Rank, simulador de quiniela, auditoría RNG, pruebas de estrategias y simuladores).
**La webapp (`webapp/backend`) los importa**, así que la app los necesita.
Incluye `reports/` con resultados congelados (p. ej. `chance_rank_v1/predictions/pos1.npz`) que la app verifica al iniciar.
Los datos de entrada están en `../datos/`.
