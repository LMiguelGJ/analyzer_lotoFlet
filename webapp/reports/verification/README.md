# Verification archive — LW15–LW18

Selected, durable evidence from the local acceptance harnesses. This archive is **not** a product runtime, a full test suite, a WCAG certification, or a claim that the harnesses can be rerun from these files. Commands and stopped-process/temporary-path references inside reports are **historical provenance**; launch scripts, browser profiles, databases, caches, PID/stop files, and the LW17 OS-temporary runtime are not bundled. The parent removed the isolated LW17 OS-temporary runtime after a read-only owned-process check (175 files, 4,874,833 bytes); this does not change the historical measurements.

`selection-manifest.json` records each retained file's source-relative path, original byte count/hash, archived byte count/hash, and whether its text was path-redacted. JSON values were decoded and checked against a transformation limited to absolute path redaction; metrics and source hash fields were not recalculated or changed. Screenshots were copied byte-for-byte. Personal Windows home/repository and temporary path prefixes were replaced with `<repo>`, `<runtime>`, `<os-temp>`, or `<user-home>`; `pytest-of-<user>` masks the test-run account. Paths remaining in source-integrity manifests are repository-relative. The source SHA-256 fields in the selection manifest describe the **historical pre-redaction files**, not a promise that those discarded source files remain present.

## Cleanup boundary

The four original `.lw*` harness directories, `.vitest/`, and root `node_modules/.vite/` are disposable **only after** archive/link/privacy verification and a fresh read-only owned-process check. Their removal is delegated to the parent; it is not claimed by this archive. The frontend's installed dependencies and `frontend/dist/` remain necessary for the local application. The parent separately owns `.playwright-cli/` cleanup. Frozen JSON/NPZ inputs, reference oracle, product source/tests, and installed frontend dependencies are out of scope.
