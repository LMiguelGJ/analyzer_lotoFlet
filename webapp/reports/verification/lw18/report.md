## Computed contrast — bounded, not WCAG certification

`contrast-corrected.json` records screen, state, identifiable label, CSS selector, computed foreground/background hex, WCAG luminance ratio, font size/weight, applicable 4.5:1 normal text / 3:1 large text or non-text threshold, and result. It walks ancestral backgrounds and composites alpha; backgrounds with visible images/gradients, opacity or unsupported colors become **manual**, not invented passes. The opaque application shell obscures the body's decorative gradient on these sampled elements. Disabled controls are excluded; no disabled control happened to be sampled. Border color without a visible border width is **not applicable**. Do not extrapolate the limited selector list to unsampled icons, placeholder text, all statuses, or every focus state.

- Corrected live sample: **93 populated PASS**, **37 selectors not observed**, **6 no-visible-edge not applicable**; wizard validation error **3 PASS** (alert text 11.27, adjacent field text 8.85, field border 3.29); explicitly injected network error **2 PASS** (text 11.27, retry text 7.48). No measured threshold failure. `contrast-corrected.json` has three `focused` entries **not observed** because the preceding pointer action did not produce `:focus-visible`; that is not a focus contrast failure.
- A separate actually keyboard-visible focused queue button in `followup.json.focus_contrast` measured text 8.11:1, 1px border 4.07:1, 2px solid outline 7.48:1 against computed background. An actual focused wizard select had a 2px solid computed accent outline. Initial representative muted text 8.11:1 on background, navigation muted 7.17:1 on surface, control border 3.29:1 on field. No placeholder was rendered by sampled inputs; status/success color was not captured in the corrected set.
- Some text colors are sampled over a fully opaque inner surface; focus outline ratio is evaluated against the control's computed background, not every adjacent exterior pixel. Alpha/gradients/images without a resolvable opaque cover would require manual review. This is not an axe run or a blanket WCAG AA verdict.
