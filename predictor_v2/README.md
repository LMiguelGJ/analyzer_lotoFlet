# predictor_v2/

Predictor bayesiano con validación walk-forward para Loteka (paquete Python con sus propias pruebas en `tests/`).
Es independiente de la webapp: **la app no lo necesita**.
Lee `datos/loteka_numbers.json` por defecto.
Uso: `python -m predictor_v2 --help` desde la raíz del repositorio.
